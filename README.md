# 🩺 VytalCare

> **Your Health. Smarter. Simpler. Always With You.**

VytalCare is an AI-powered healthcare assistant that combines intelligent medical guidance, health tracking, prescription management, and emergency support into a single modern web application.

🌐 **Live Website:** https://vytalcare.site

---

## 📖 Overview

VytalCare is a comprehensive digital healthcare platform built to help users take control of their health through AI and wearable technology.

The platform integrates health data from wearable devices, provides intelligent medical assistance using Large Language Models (LLMs), enables AI-powered prescription scanning, manages medication reminders, and visualizes daily health metrics through an intuitive dashboard.

Whether you're monitoring your daily fitness, organizing medications, or seeking reliable healthcare information, VytalCare serves as your personalized healthcare companion.

# 🚀 Getting Started

## Clone the repository

```bash
git clone https://github.com/<username>/VytalCare.git
```

## Navigate into the project

```bash
cd VytalCare
```

## Install dependencies

```bash
npm install
```

## Run locally

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173
```

---

# 🔑 Environment Variables

Create a `.env` file in the project root.

```env
VITE_FIREBASE_API_KEY=
VITE_FIREBASE_AUTH_DOMAIN=
VITE_FIREBASE_PROJECT_ID=
VITE_FIREBASE_STORAGE_BUCKET=
VITE_FIREBASE_MESSAGING_SENDER_ID=
VITE_FIREBASE_APP_ID=

VITE_GOOGLE_CLIENT_ID=

VITE_GEMINI_API_KEY=
VITE_GROQ_API_KEY=
```

# 📷 AI Prescription Scanner

Users can upload an image of their prescription.

VytalCare automatically:

- Detects medicine names
- Extracts dosage
- Identifies medication timings
- Creates reminders
- Saves medications to the user's profile

This reduces manual effort while improving medication adherence.
